# Cyber World University

Cyber World University (CWU) is an open-source cybersecurity education initiative focused on accessible cybersecurity learning.

## Focus

- Cybersecurity education
- Ethical hacking education
- Network and web security learning
- Digital security awareness
- Practical learning resources
- Open-source educational software

## Current Work

I am developing CWU as a structured online learning platform with courses, lessons, quizzes, examinations, student progress, certificates, and administration features.

## Project

Main repository:

`https://github.com/cyberworlduniversity/Cyber-World-University`

## Goals

- Make cybersecurity education more accessible.
- Help beginners build strong cybersecurity foundations.
- Provide organized learning resources.
- Improve practical and responsible security education.
- Build secure, maintainable open-source software.

## Contributions

Contributions, educational feedback, documentation improvements, testing, security improvements, and responsible open-source development are welcome.
